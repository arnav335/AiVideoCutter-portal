Put official logo files here, named like youtube.png, mrbeast.png, skool.png.

A file named `<brand>.png|jpg|jpeg|webp|svg` is used as it is for every picture of that brand (nothing is generated).
It is centred on a flat dark (#121212) full frame. SVG needs the optional `sharp` package (`npm install sharp`).
On the B-roll tab, a generated logo has a "Save as logo" button that puts the picked image here for you.
